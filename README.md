# 🌌 Chaos Art Generator

The **Chaos Art Generator** is an interactive visualization tool that brings mathematical attractors to life. Explore stunning chaotic systems like the Lorenz, Rössler, Henon Map, and the custom Eclipse Vortex, with real-time parameter adjustments, gradient-colored plots, and dynamic explanations for each attractor.

## 🚀 Features
- Real-time graph updates as you adjust parameters.
- Stunning gradient-colored 2D and 3D plots.
- Dynamic explanations and equations for each attractor.
- Four attractors to explore: 
  - Lorenz Attractor
  - Rössler Attractor
  - Henon Map
  - Eclipse Vortex Attractor (custom).

## 🛠️ Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/chaos-art-generator.git
   ```
2. Navigate to the project folder:
   ```bash
   cd chaos-art-generator
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   streamlit run chaos_ui.py
   ```

## 📚 Technologies Used
- **Python**
